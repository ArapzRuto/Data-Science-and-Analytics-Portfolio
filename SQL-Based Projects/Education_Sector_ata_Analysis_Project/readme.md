#  Data Analysis: Education Sector Data

## Introduction

This project focuses on performing SQL data analysis on a cleaned **Education Sector** dataset containing information about students, schools, teachers, subjects, academic performance, attendance, and fee payments.

Using **PostgreSQL**, the project applies a wide range of SQL techniques to solve real-world business problems and generate actionable insights that support data-driven decision-making within the education sector.

Throughout the analysis, various SQL concepts and techniques were used, including:

- Aggregate Functions
- Window Functions
- Subqueries
- Common Table Expressions (CTEs)
- Joins
- CASE Statements
- Date Functions
- Views
- Stored Procedures
- User-Defined Functions

The project demonstrates practical SQL skills in querying, data transformation, business analysis, and reporting, showcasing how relational databases can be used to answer analytical questions and support strategic decision-making.
